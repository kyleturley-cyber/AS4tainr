# Known fidelity gaps

These are places where as4tainer knowingly behaves differently from IBM i. Each one should eventually turn into a fix with a test, or into a documented decision.

| Area | IBM i behavior | as4tainer today | Impact |
| --- | --- | --- | --- |
| Key collating sequence | Character keys are ordered by EBCDIC: lowercase before uppercase, and letters before digits | Byte order of UTF-8 text (`COLLATE "C"`): digits before uppercase before lowercase | Mixed letter/digit or mixed-case keys read in a different order. Planned fix: an EBCDIC sort key per character key field |
| Record locking | Update files lock the record read until UPDATE, DELETE, the next read, UNLOCK or close; WAITRCD per file; SQL and record-level access respect each other's locks | RPG reads lock as on IBM i (see record-locks.md); one wait time for all files (`AS4TAINER_WAITRCD`, 60 seconds); SQL and CL neither take nor wait for record locks; free-form N/E extenders and UNLOCK are not seen | A SQL UPDATE can change a record a program has locked |
| Commitment control | `COMMIT`/`ROLBK` under journaling | Each operation autocommits | No rollback of partial work |
| Field types | A, P, S, B, I, U, F, L, T, Z, G, O, H... | A, P, S only | Files using other types are rejected at CRTPF (dates `L`, times `T` and timestamps `Z` are common in real files: next) |
| Source files and objects | Source physical files with SRCSEQ/SRCDAT/SRCDTA records; members added with ADDPFM, edited with SEU/RDi; programs compiled to machine code; CRTRPGPGM (RPG III), CRTSQLRPGI, CRTCMD, CRTPRTF, CRTSRVPGM/CRTPGM (modules, service programs, binding directories) | Members are text (`as4tainer.source_members`), not records; CRTSRCPF, CRTPF/CRTLF/CRTDSPF, CRTBNDCL/CRTCLPGM (checked) and CRTBNDRPG (kept as source; checked when called) from SRCFILE/SRCMBR; DSPFD TYPE(*MBRLIST); DSPPFM of a member. No ADDPFM/RMVM/CHGPFM, no member editing; SQLRPGLE, RPG III, CMD, PRTF, COBOL, modules and service programs are kept as source only | Programs with embedded SQL, command definitions, DDS printer files and service programs do not build yet |
| `as4tainer import` | (no IBM i equivalent; replaces SAVF/RSTLIB or a TOBi/BOB build) | Builds PF (loading CSV), LF, DSPF, CL and RPGLE members; include files (`*.rpgleinc`, `*.clleinc`) become stream files | See docs/import.md |
| Native RPG engine (R1, R2) | ILE RPG as compiled by CRTBNDRPG | Batch and interactive programs: see docs/rpg-engine.md for what R1 and R2 cover. Not yet: READ of a display file record, program-described WORKSTN files, DSPLY with a response (batch: the response stays unchanged; interactive: no prompt is shown yet), printer files and O specs, procedures and prototypes (CALLP, `ctl-opt main`), CALL from RPG, `*LDA`, MOVEA/LOOKUP/SCAN/CHECK/XLATE/SUBST opcodes, dates and times, floating point, pointers, numbers over 38 digits, `%CHAR` of a value below 1 shows no leading zero (to be checked against a real system) | Programs fail with "not supported by the native engine yet"; Jariko stays the default until R5 |
| CL programs | The full CL language and command set, parameters passed by reference | The subset in cl-programs.md; parameters by value; no files in CL (DCLF/RCVF), OVRDBF, RCVMSG, RTVSYSVAL; *DEC to *CHAR in CHGVAR gives digits with leading zeros (to be checked against a real system). CL `INCLUDE` (SRCSTMF, SRCMBR) is expanded when the program is created; DCLPRCOPT and COPYRIGHT are accepted and ignored; `TYPE(*PTR)`, `STG(*DEFINED)`/`DEFVAR` are not supported yet | Programs using unsupported statements fail at CRTBNDCL with the line number |
| SQL | DB2 for i SQL: DDL, commitment control, embedded SQL (SQLRPGLE), QSYS2 catalog views, all scalar functions and special registers | SELECT/VALUES/INSERT/UPDATE/DELETE, one at a time, autocommitted, with the translations in sql.md; PostgreSQL semantics otherwise (e.g. character comparison and sort order) | Statements outside the subset fail with SQL0084 or SQL0104 |
| Logical files | Keyed and selected views over physical files, join logical files, several record formats, RENAME/CONCAT/SST, DYNSLT | One physical file per logical file, one record format, a subset of its fields, keys (DESCEND), select/omit with COMP/VALUES/RANGE/ALL, UNIQUE (see logical-files.md) | Join and multi-format logical files are rejected at CRTLF |
| CHAIN not found | No current record; next READ position is not well defined in all cases | The next READ starts at the searched key | Programs that rely on this undefined behavior may differ |
| Object names | National characters allowed in some CCSIDs | ASCII A–Z, 0–9, `$#@_.` only | |
| Null-capable fields | `ALWNULL` | Not supported | |
| Character data | EBCDIC CCSIDs (37, 500, ...) | UTF-8 in PostgreSQL | Hex constants and byte-level tricks (`%BITAND` on text) differ |
| Jariko DSPLY output | DSPLY writes to the job's external message queue | Jariko prints the message on standard output | Fine for tests; operator messages come later |
| 5250 sessions | Many session and device options | 24x80 only; no TLS (992), no NEW-ENVIRON auto sign-on or device naming | Use only on trusted networks for now; telnet sends passwords in clear text |
| Browser terminal | A 5250 display station: Attn, SysReq, Print, Help on a field, Dup, Erase Input, cursor select, 27x132, DBCS, Save/Restore Screen | Display station in `core/src/web` (see web-terminal.md): 24x80 only; no Attn, SysReq or Print keys; Field+/Field− and right-adjust are simplified; mandatory enter/fill and field exit required are not enforced; no TLS of its own | Use a TLS reverse proxy outside trusted networks; programs that rely on Attn or SysReq can't be driven from the browser yet |
| Sign-on security | QMAXSIGN / QMAXSGNACN can disable the profile or the device | The connection closes after 3 failures; profiles are never disabled | Repeated guessing is slowed but not blocked across connections |
| Library list | System values QSYSLIBL and QUSRLIBL; product libraries (`PRD`); QTEMP is private to each job and empty at sign-on; DSPLIBL shows the ASP device | The system part is fixed (QSYS, QSYS2, QHLPSYS, QUSRSYS); the user part comes from `AS4TAINER_LIBL`; no product libraries; QTEMP is one shared library; no ASP column; EDTLIBL is missing | Objects put in QTEMP are visible to other jobs and are not deleted at sign-off |
| Command entry | F4 prompting with help, F9 (all parameters), F10 (additional parameters), "+ for more values" on list parameters, job log, message queues | F4 prompts every parameter on one screen; list parameters are one text field; no help; messages shown in the session log only | Prompts look plainer; long lists are typed as `'a' 'b'` |
| CRTUSRPRF, CHGUSRPRF | About 60 parameters | USRPRF, PASSWORD, PWDEXP, STATUS, USRCLS, CURLIB, TEXT, SPCAUT, INLPGM, INLMNU (CHGUSRPRF: no PASSWORD, USRCLS or SPCAUT). `*SECADM` is needed for CRTUSRPRF, CHGUSRPRF, DLTUSRPRF and other users' DSPUSRPRF; object authority is in object-authority.md | No group profiles, job descriptions, output queues, LMTCPB or other attributes |
| Menus | MAIN and about 100 system menus; CRTMNU TYPE(*DSPF) (display file + message file of option commands) and TYPE(*UIM); GO with generic names and RTNPNT; F23 sets the initial menu; Attn shows the Attention program | as4tainer's own system menus (MAIN, USER, JOBS, FILES, PROGRAM, SECURITY) with as4tainer's texts; CRTMNU TYPE(*PGM) only; GO MENU only; no F23, no Attn; an initial menu that is not found opens Command Entry with a message | Menus of legacy apps built as *DSPF or UIM menus must be rewritten as *PGM menus (a program with a display file) for now |
| WRKOBJ | A list with options (2=Edit authority, 4=Delete, 5=Display, ...) | The list only; object types `*LIB` and `*FILE` | |
| DSPPFM | Shows the raw record image (zoned digits, packed as hex), F10/F11 hex view, position to line | Fields separated by a blank, numbers as decimal text, at most 9999 records; F19/F20 shift | Easier to read than the real one, but not identical |
| Password level (QPWDLVL) | Levels 0-3 change case rules, length (10 at 0/1, 128 at 2/3) and allowed characters | `AS4TAINER_QPWDLVL` sets case: 0/1 (default) not case sensitive, 2/3 case sensitive. Length is at most 28 at every level; allowed characters are not checked | A password valid on as4tainer may be too long or use characters IBM i rejects at level 0/1 |
| Jobs and subsystems | Subsystem descriptions, job queues, job descriptions, routing, priorities, holding, ENDJOB of active jobs, WRKSBS | Subsystems QINTER (sessions) and QBATCH (one job queue, first in first out) in the server process; JOBD is always QDFTJOBD; ENDJOB only for jobs still on the queue (see work-management.md) | Batch work runs, but cannot be scheduled, held or cancelled once running |
| Job logs and messages | Job logs are spooled (QPJOBLOG) at LOG level; message queues with inquiry messages, replies, break delivery, message files | Job logs are kept in the catalog for every job; user message queues with informational messages only; "message waiting" is shown on the command line message, not the MW indicator | No replies, no message files |
| Object authority | Owner, *PUBLIC, private authorities, authorization lists, group profiles, specific authorities, library authority, checked on every object access | Owner, *PUBLIC and private *ALL/*CHANGE/*USE/*EXCLUDE, *ALLOBJ; checked on file open and record changes, display files, CL CALL, data areas (see object-authority.md); RPG programs, libraries and SQL are not checked | A user can call any RPG program |
| Printer files and spooled files | Program-described and externally described printer files, cycle output (H/D/T), OA-OG, edit words, PRTCTL, output queue management, real printers | Program-described printer files with EXCEPT (E records), space/skip, edit codes 1-4 J-M Z Y, OFLIND, pages of 66 lines with overflow at 60; spooled files with WRKSPLF/DSPSPLF/DLTSPLF (see spooled-files.md) | Cycle-driven reports and DDS printer files do not print yet |
| Data areas | `*CHAR`, `*DEC`, `*LGL` data areas; `*LDA`, `*GDA`, `*PDA`; lock waits end after the job's default wait time | `*CHAR`, `*DEC`, `*LGL` (see data-areas.md); no `*LDA`/`*GDA`/`*PDA`; `CHGDTAARA` waits for a `*LOCK` without a time limit; `RTVDTAARA` of a `*DEC` data area needs a `*DEC` variable | Programs using the local data area cannot run yet |
| CL completion messages | Completion messages of commands run inside a CL program go to the program's message queue | They are shown in the job log after the CALL (e.g. "Data area ORDNXT created") | More messages on the command entry screen |
| Display files | Full DDS for display files | Common subset (see display-files.md): no `PUTOVR`/`OVRDTA`, `WINDOW`, `REF`/`REFFLD`, `VALUES`/`RANGE`/`COMP`, `EDTWRD`, help, `INDARA` | Programs using windows cannot run yet; validity checking keywords are not enforced |
| Subfiles | All subfile keywords | `SFL`, `SFLCTL`, `SFLSIZ`, `SFLPAG`, `SFLDSP`, `SFLDSPCTL`, `SFLCLR`, `SFLDLT`, `SFLEND(*MORE/*PLUS)`, `SFLNXTCHG`, `SFLMSG`, `PAGEUP`/`PAGEDOWN`. Not yet: `SFLRCDNBR` (the first page is always shown), `SFLINZ`, `SFLFOLD`/`SFLDROP`, `SFLLIN` (side-by-side records), `SFLCSRRRN`, message subfiles (`SFLMSGRCD`), `SFLEND(*SCRBAR)` shows as `*MORE` | Load-all and page-at-a-time subfiles work; position-to and folded lists do not |
| Display I/O operations | EXFMT, WRITE, READ, READC, CHAIN/UPDATE of subfile records | EXFMT, WRITE, READC, CHAIN and UPDATE of subfile records. Not yet: WRITE followed by a separate READ of a display file, `READ` of a WORKSTN file name, free-form `DCL-F` with `SFILE` | A WRITE is shown with the next EXFMT, not immediately; a program that writes a record and then waits (no input) shows nothing |
| Records on the screen | Input fields of every record on the screen can be typed into | Only the record being read (and its subfile) takes input; other records are output only | Rare in practice |
| Numeric display fields | Unedited output shows the field's digits; input positions follow the data type | Unedited output shows digits, a decimal point and a sign position | Screen layouts with unedited numeric fields can be wider by one or two positions |
| DATE / TIME constants | Job date in the job's date format; local time | MM/DD/YY and HH:MM:SS in UTC | |

## Gaps in Jariko (the RPG runtime)

These are RPG features Jariko does not support yet. They are worth contributing upstream to [smeup/jariko](https://github.com/smeup/jariko).

| Feature | Jariko v2.2.0 | Workaround |
| --- | --- | --- |
| `%FOUND(filename)` | Fails with "%FOUND expression with file names is not implemented yet" | Use `%FOUND` with no argument right after the file operation |
| `ITER` inside `DOW` | `DOW` catches `LEAVE` but not `ITER` (`DO`/`DOU` handle both); the program ends with IterException | Restructure with `IF`/`ELSE`; a one-line upstream fix |
| Same field in two files with different numeric types | "Incongruous definitions" when a name is packed in one file and zoned in another | as4tainer declares numeric fields of database and display files as packed, as RPG does for externally described input fields |
| Fully free-form source (`**FREE`) | Not supported: the program parses and does nothing, silently | None yet. A free-form to fixed-form translation in the runner is the next step (found with the corpus in docs/import.md) |
| Free-form declarations (`DCL-S`, `DCL-DS`, `DCL-F`, `DCL-PR`, `DCL-PROC`...) | Not supported, in `**FREE` or fixed-form source | Use D, F and P specs for now |
| `RETURN` with a value in free-form calculations | "An operation is not implemented" | Fixed-form `C RETURN expression` works |
| Free-form calculations without `/FREE` (IBM i 7.1 TR7 and later allow them in columns 8-80) | Not recognized | Wrap them in `/FREE` ... `/END-FREE` |
| `/COPY`, `/INCLUDE` of a quoted stream file (`'header.rpgleinc'`) | Only `file,member` ids are recognized | The as4tainer runner replaces quoted includes with the stream file's lines before parsing |
| `//` comments in columns 1-5 of fixed-form source | Read as code | The as4tainer runner blanks such lines (IBM's compiler ignores columns 1-5) |
| Indicators on database operations | READ/READE/READP did not set the end-of-file indicator in positions 75-76, CHAIN not the not-found indicator in 71-72, unless the file layer says so | The as4tainer file layer sets them (fixed: loops like `DOU *IN99` ran forever) |
| Function key indicators `*INKA`-`*INKY` | Not set by the display callback | The as4tainer runner sets them from the key pressed at each EXFMT (Jariko numbers them 105-128) |
| Startup output | Prints a version banner and feature flags on standard output | The as4tainer launcher redirects it to standard error |
| CHAIN cache | `ChainCacheFlag` is on by default: a repeated CHAIN with the same key is answered from memory, so it misses other jobs' changes, and the following UPDATE can change the wrong record | The as4tainer runner turns the flag off (found with the order entry sample) |
| File type, N/E extenders, UNLOCK | Jariko's file layer is not told whether a file is opened for update, nor about N (no lock) and E (error goes to %ERROR) on reads; UNLOCK does nothing | The as4tainer runner reads the F specs and puts signal statements in front of such reads and of UNLOCK (fixed form only); see record-locks.md |
| `*DTAARA DEFINE` / `IN` / `OUT` | Supported through callbacks that pass only text | The as4tainer runner sets the program field itself, so a numeric field gets a `*DEC` value as a number. `UNLOCK *DTAARA` and the D-spec `DTAARA` keyword are not supported |
| WORKSTN operations other than EXFMT | `WRITE`/`UPDATE` of a display record look for a database file; `READC` parses but does nothing; `SFILE` is not used | Before parsing, the as4tainer runner declares each display record format as a DISK file served through the bridge, and rewrites `READC sfl` as `READ sfl`. Error messages from Jariko then show line numbers a few lines higher than the source (the added F specs). See display-files.md |
